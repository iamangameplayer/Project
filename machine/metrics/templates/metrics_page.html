Regression Metrics

Regression metrics help evaluate how well a machine learning model predicts continuous numerical values. Each metric measures prediction quality from a different perspective, helping us understand both accuracy and error behavior.

Why Metrics Matter

After training a regression model, we need a way to measure its performance. Metrics compare predicted values with actual values and quantify the model's accuracy.

Some metrics focus on average error, some penalize large mistakes more heavily, and others indicate how much variance in the target variable is explained by the model.

R² Score

Measures how much variance in the target variable is explained by the model.

R² = 1 - (SSres / SStot)

Higher is better. Maximum value is 1.

MAE

Mean Absolute Error calculates the average absolute difference between actual and predicted values.

MAE = (1/n) Σ |y - ŷ|

Lower values indicate better predictions.

MSE

Mean Squared Error squares prediction errors before averaging, making large errors more significant.

MSE = (1/n) Σ (y - ŷ)²

Strongly penalizes large prediction mistakes.

RMSE

Root Mean Squared Error is the square root of MSE and has the same unit as the target variable.

RMSE = √MSE

Easier to interpret than MSE.
